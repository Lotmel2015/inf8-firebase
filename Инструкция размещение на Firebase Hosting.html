Как разместить курс на Firebase Hosting

Пошагово: создать проект Firebase, подключить курс к Firestore (обезличенно, по коду ученика), задеплоить на бесплатный хостинг Firebase и открыть ссылку ученикам. Подходит для учителя без глубокого опыта в веб-разработке.

0 ₽бесплатный тариф Spark
≈ 30 минот нуля до рабочей ссылки
Без ФИОученик входит по личному коду
НуженNode.js 18+ · аккаунт Google · GitHub
Важное ограничение (повторяем из плана): Firebase и консоль Google из РФ работают нестабильно из-за блокировок. Перед началом убедитесь, что console.firebase.google.com открывается с вашего интернета. Если нет — курс всё равно работает локально, просто без онлайн-сбора.

1Создать проект Firebase

  1. Открой консоль Firebase и войди в аккаунт Google Адрес: console.firebase.google.com. Если просит войти — войди в свой Google-аккаунт.
  2. Нажми «Создать проект» Название проекта, например inf8-progress. Отображаемое имя можно менять; технический projectId менять нельзя — запиши его (пригодится в шаге 6).
  3. Аналитику для этого проекта можно НЕ включать Для курса она не нужна, а отключённая упрощает согласование с учителем по персональным данным.
  4. Дождись создания и нажми «Продолжить» Проект появится в списке. Слева появится меню — нам понадобятся разделы «Firestore Database» и «Hosting».

2Создать базу Firestore

  1. Слева выбери «Firestore Database» → «Создать базу данных»
  2. Регион: выбери ближайший к тебе (например europe-west1 — Бельгия) Регион менять потом нельзя. Для школы подойдёт европейский; латентность не критична.
  3. Режим: выбери «Режим ограниченного доступа» (не «тестовый») Тестовый режим открывает базу всем на 30 дней — этого нельзя. Ограниченный — закрывает всё по умолчанию.
  4. Дождись создания базы (несколько секунд)

3Настроить правила Firestore (защита)

  1. В разделе «Firestore Database» открой вкладку «Правила»
  2. Вставь эти правила вместо стандартных 
    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /progress/{code}/out/{task} {
      allow read: if request.auth == null
          && code.matches('^[A-Z0-9-]{4,10}$');
      allow create: if request.auth == null
          && request.resource.data.code == code
          && code.matches('^[A-Z0-9-]{4,10}$');
      allow update: if request.auth == null
          && request.resource.data.code == code
          && code.matches('^[A-Z0-9-]{4,10}$');
      allow delete: if false;
    }
  }
}
    Курс пишет результаты в подколлекцию progress/{код}/out/{урок.задание} (документ = одно задание). Поэтому правило объявлено именно для /out/{task}: правила родительского документа на подколлекции не распространяются. При создании/обновлении проверяем, что поле code внутри документа совпадает с кодом из пути — чужие записи изменить нельзя. Читать можно только свою подколлекцию. Удаление запрещено.
  3. Нажми «Опубликовать» Если правила не применились — проверь, что база в режиме ограниченного доступа (шаг 2).

4Добавить веб-приложение и получить ключи

  1. В настройках проекта (шестерёнка) → «Настройки проекта» → вкладка «Ваши приложения»
  2. Выбери «Веб-приложение» (значок </>) Название приложения, например course-web.
  3. Скопируй объект firebaseConfig — он понадобится в шаге 6 
    { "apiKey": "AIza...", "authDomain": "inf8-progress.firebaseapp.com",
  "projectId": "inf8-progress", ... }
    Внимание: apiKey из клиентского кода — не секрет (Firebase это документирует). Защита держится на правилах из шага 3, а не на ключе.

5Разместить курс на GitHub (уже сделано)

  1. Репозиторий создан автоматически: github.com/Lotmel2015/inf8-firebase В нём — файл курса «Онлайн курс информатики 8 класс.html». Это страница-приложение: её же будем деплоить на Firebase.
  2. Как обновлять курс позже: После изменения файла просто коммитим и пушим (если настроено) — инструкция в шаге 8.

6Вставить ключи Firebase в курс

  1. Скачай последнюю версию курса из GitHub Открой репозиторий → файл «Онлайн курс информатики 8 класс.html» → кнопка «Download raw file» (скачать). Сохрани рядом с собой, например в папку C:\inf8-course.
  2. Открой файл в текстовом редакторе (Блокнот, VS Code)
  3. Найди блок конфигурации и замени REPLACE_ME своими значениями 
    var FIREBASE_CONFIG = {
  apiKey: "AIza...",
  projectId: "inf8-progress",
  authDomain: "inf8-progress.firebaseapp.com"
};
    Значения — из firebaseConfig в шаге 4. Не удаляй кавычки и запятые: иначе курс перестанет запускаться.
  4. Сохрани файл

7Установить Firebase CLI и задеплоить

  1. Установи Node.js 18+ Скачай и установи с nodejs.org (LTS). После установки перезапусти терминал.
  2. Открой терминал (PowerShell) в папке с курсом 
    cd C:\inf8-course
  3. Установи Firebase CLI 
    npm install -g firebase-tools
  4. Войди в Google-аккаунт (откроется браузер) 
    firebase login
  5. Инициализируй хостинг в папке курса 
    firebase init hosting
    Отвечай: использовать существующий проект inf8-progress → Да; public directory: .; одностраничное приложение (SPA): N (у курса свои хэш-роуты, редирект не нужен). Создавать файлы по умолчанию — можно согласиться.
  6. Задеплой 
    firebase deploy --only hosting
    В конце появится URL вида https://inf8-progress.web.app — это и есть адрес курса.

8Проверить и раздать ссылку

  1. Открой URL курса (например https://inf8-progress.web.app) в браузере
  2. Проверь вход ученика по коду Вкладка «Ученик» → личный код (например X7-K2P) + класс. Без ФИО.
  3. Реши пару заданий, затем открой «Мой прогресс» Данные должны подтянуться из Firestore (нужен доступ к интернету).
  4. Проверь со стороны учителя: в консоли Firebase → Firestore → коллекция progress Видны документы с кодом и баллами; ФИО там нет. Это и есть обезличенная схема.
  5. Раздай ученикам ссылку и личные коды Коды — уникальные (например A8-101, A8-102…), раздавай лично. Учитель ведёт таблицу «код → ФИО» у себя.
Готово. Курс открывается по ссылке, результаты собираются в Firestore под обезличенными кодами, учитель видит прогресс в консоли Firebase. Чтобы обновить курс позже: измени файл, снова firebase deploy --only hosting.
Если на шаге 7 что-то не работает из-за блокировок: Firebase CLI при первом входе открывает страницу Google. Если она не открывается — используйте вариант с VPS (см. план «План отслеживания прогресса учеников.html»): он работает из РФ стабильно.

Типичные ошибки

ПроблемаПричина и решение
«URL не открывается»Проверь, что деплой завершился (вывод об успехе), и что набран точный URL .web.app.
«Ошибка Firebase initialization: no matching project»Выбери существующий проект при firebase init hosting — проект из шага 1.
«Мой прогресс» пустойПроверь доступ к интернету; проверь, что ключи вставлены (шаг 6); проверь правила (шаг 3) — allow create/read по коду.
«Синхронизация не настроена» на странице «Мой прогресс»Ключи всё ещё REPLACE_ME — вставь свои из шага 4, пересохрани, передеплой.
Вход не принимает кодКод — 4–10 латинских букв/цифр/дефисов, верхний регистр. Пример: X7-K2P.

Что можно сделать ещё

  • Вести таблицу учителя «код → ФИО» в Excel и сопоставлять с данными консоли.
  • Экспортировать результаты в CSV (скрипт admin из плана Firebase) для электронного журнала.
  • Привязать свой домен (например inf8.myschool.ru) в Hosting → «Подключить домен».
